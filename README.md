# 🌕🌓🌗🌑 MOONFASE 

<p> Aplicação processa uma String fornecida no formato "yyyy-mm-dd" , que internamente é convertida</p>
em LocalDate e retorna uma fase da lua.</p>

<p> O ciclo lunar é algo complexo, havendo fases que duram de 6 a 9 dias, sendo este aplicativo uma aproximação, tão somente</p>
<p>com o intuito de aprendizado na implementação do algoritmo encontrado na web, que é:</p>

<pre>(((year + 2) * 11) + day + month) % 30</pre>

## Uso

- Acople o sofware como módulo em seu projeto.
- Agora, em seu projeto ficará disponível a classe <i>App_MoonFase</i>
- Esta classe, prove o método <pre>calculateOfFase()</pre>

## Considerações
-É um projeto apenas didático, não deve ser usado em projetos profissionais.
